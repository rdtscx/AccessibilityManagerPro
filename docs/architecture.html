无障碍管理器 Pro · 原理与架构 v1.4.1 · 适配 Android 5.0(API 21)~17 · release 1.86MB · 前台服务类型修复/锁定图标优化
示意：按本应用实际实现绘制的分层结构与四条自动化闭环（自监控 / 服务保活 / 应用保活 / 通知调控）
① 系统侧 · Android 平台（API 21~37 全版本守卫，低版本自动降级）
AccessibilityManager
读取已安装/已启用无障碍服务 · 本应用低耗电服务仅监听窗口事件（不读屏幕内容）
Settings.Secure
enabled_accessibility_services 组件串 + accessibility_enabled · 数据库变更触发 ContentObserver（零轮询）
UsageStatsManager
前台/停止事件 → 判定目标应用是否掉线（需"使用情况访问"，API 21 返回空不崩溃）
NotificationManager / Settings.Global·System
通知拦截与重要性 · 开发者选项键值（动画缩放 / 不保留活动 / GPU 渲染…）
② 授权通道（写系统安全设置 / 执行系统命令所需，自动探测最佳通道）
ADB 已授权
pm grant WRITE_SECURE_SETTINGS 后应用内直写
Root
su -c settings / cmd notification …
Shizuku
:shizuku 进程 UserService 以 shell 权限执行命令 · 仅 Android 7.0+ 可用，低版本通道静态禁用
无通道（降级）
跳转系统设置手动开启 · 通知 0/1 档仍可拦截
③ 应用核心引擎（四大模块 · 已做内存/耗电优化）
SelfGuardService（前台）
ContentObserver 监听 Settings.Secure 数据库变更（零轮询省电）→ 检测到本应用无障碍被关闭 → 延迟 1 秒 → 写回拉起 · Android 14+ 声明 specialUse 前台服务类型
SelfAccessService + KeepAliveEngine
窗口事件驱动 + 低频巡检（默认 30s）→ 判定掉线 → 后台无感拉起 · 单应用冷却防循环 · 空名单零调度 · 图标/扫描双缓存省内存
NotifGateService（通知使用权）
每应用 0-5 级：0 拦截 / 1 静默 / 2 低 / 3 标准 / 4 高 / 5 最高（精细升降级需通道 + Android 14+，低版本自动放行不崩溃）
DevOptions + WatchdogService
开发者选项直写（直写 → Root/Shizuku 兜底，Settings 持久化永久生效）· 服务级保活看门狗周期巡检 · 动画档位滑杆 0-10
无障碍权限总控 + 权限管理（v1.2）
全机无障碍服务开关 + 锁定自动恢复（并入 ContentObserver 自监控）· 权限狗式危险权限组查看与 pm grant/revoke（Root/Shizuku）
④ 自监控闭环（ContentObserver，无轮询）
Settings.Secure 变更回调
→
本组件是否还在启用串
→

→

↺ 被用户/系统关闭 → 延迟 1 秒立即拉起；无通道时通知并跳转系统设置（系统限制，无法静默自启）
⑤ 应用保活闭环（v1.4：掉线立即拉起 → 100ms 返回，后台无感）

→
